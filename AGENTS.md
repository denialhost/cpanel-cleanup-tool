# Preferencias de publicación

Cuando se publique este proyecto en GitHub, incluir capturas actuales de la interfaz para que los usuarios puedan revisar el producto antes de instalarlo.

- Mostrar al menos dos vistas representativas en el README y enlazarlas desde las notas de la versión.
- Mantener las imágenes en `docs/screenshots/` y renovarlas cuando cambie la interfaz correspondiente.
- Usar datos de demostración o anonimizados e identificar las simulaciones; no presentar una demo como validación en un servidor real.
